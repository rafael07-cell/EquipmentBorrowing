Part A. REQUIREMENT ANALYSIS

A. Actors
Actor student
 The only actor on this system. The Student interacts directly with the system to:
- Request to borrow available equipment
- Return equipment they previously borrowed
- Check whether a specific piece of equipment is currently available

  The Student expects the system to automatically validate their eligibility, confirm the equipment exists and is available, enforce the maximum active-borrowing limit, and accurately track which equipment they currently have borrowed — without needing any manual approval from a staff member.
